# **App Name**: AnonyCollab

## Core Features:

- Clean Slate: Provide a completely blank page upon loading, free of any headers, footers, or pre-existing content.

## Style Guidelines:

- Default theme is dark with cyan accents; also supports a light theme.
- Dark Theme Backgrounds: Main - #0a0e1a, Card - #131823, Popover - #1a1f2e
- Dark Theme Text: Primary - #e5e7eb, Secondary - #94a3b8
- Dark Theme Accent: #22d3ee (cyan)
- Dark Theme Borders: white @ low opacity (border-white/10)
- Light Theme Backgrounds: bg-gray-50, bg-white
- Light Theme Text: text-gray-900, text-gray-600
- Light Theme Accent: bg-cyan-600
